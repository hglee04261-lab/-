## 2026년 하반기 변화 메모 (강의 전 재확인)
- **NotebookLM → Gemini Notebook**으로 이름이 바뀜(2026년 7월, Google 공식 블로그). 수강생 중 옛 이름으로 아는 분이 많으니 둘 다 언급.
- **ChatGPT 커스텀 GPTs**: OpenAI가 2026년 9월 릴리스 노트에서 단계적 종료와 플러그인으로의 이전 계획을 밝힘 → 강의에서 "GPTs 만들기"는 권하지 말고 **Projects**로 안내.
- 세 서비스 모두 모델명이 자주 바뀜 → 강의에서는 모델명보다 **서비스 이름 + 기능**으로 말하기.

## Claude Code 요금제 조건 (강의 전 재확인)
- 2026년 11월 기준 여러 자료에서 **무료 요금제에는 Claude Code가 포함되지 않고, Pro 이상 또는 API 결제가 필요**하다고 함.
- 2026년 4월 Pro 요금제에서 Claude Code를 뺐다가 되돌린 '시험'이 보도된 적이 있음 → **claude.com/pricing에서 "Claude Code 포함" 문구 확인.**

## Claude 무료 요금제 프로젝트 (강의 전 재확인)
- 2026년 11월 기준 여러 자료에서 무료 계정도 **프로젝트를 최대 5개** 만들 수 있다고 함. 9월 중순 보관 자료에는 무료 'No' → 'Up to 5'로 바뀐 기록도 있어 변동 가능성 있음.
- 시연 전 무료 계정으로 프로젝트 생성·지침 입력·파일 업로드가 되는지 직접 확인.
