대상: $ARGUMENTS (비어 있으면 가장 최근 설교 폴더)

1. `06-원고.md`가 있는지 확인한다.
2. 아래 4개 서브에이전트를 **한 번에 병렬로** 실행한다. 각자에게 설교 폴더 경로와 검토 대상 파일을 알려 준다.
   - `theology-reviewer`
   - `fact-checker`
   - `homiletics-coach`
   - `congregation-voice`
3. 동시에 `/handoff gemini N` 절차로 Gemini 사실검증 패킷을 만들고, 설교자에게 "외부 검증(선택)"으로 안내한다. 원고를 Claude가 썼으므로 외부 AI 검증을 권장한다.
4. 결과를 `07-검증.md`에 종합한다:
   ```
   ## 종합
   ### 🔴 반드시 수정 (2개 이상 검증자가 지적 / 사실 오류 / 신학 수정필요)
   ### 🟡 검토 권장
   ### ⚖️ 의견 충돌 — 설교자 결정 필요 (각 근거 병기)
   ### 수치: 사실 확인됨 n / 정정 n / 확인불가 n · 설교학 평균 n점 · 낭독 예상 n분
   ## 검증자별 원문
   ```
5. 원고는 수정하지 않는다. 🔴 항목의 수정안을 제시하고, 적용할지 설교자에게 묻는다.
