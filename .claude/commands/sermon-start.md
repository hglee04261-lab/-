sermon-orchestrator 스킬을 따라 새 설교 프로젝트를 시작하세요.

입력: $ARGUMENTS

1. 입력을 `|`로 나눠 본문, 일시, 청중, 묵상요지를 얻는다. 빠진 항목은 한 번에 모아서 묻는다.
2. `sermons/<YYYY-MM-DD>-<본문약칭>/` 폴더와 `handoff/` 하위 폴더를 만든다.
3. `templates/설교-브리프.md`로 `00-브리프.md`, `templates/AI-사용기록.md`로 `AI-사용기록.md`를 만든다.
4. **S단계 게이트**: 묵상요지가 없으면 아래를 보여 주고 멈춘다. AI가 묵상을 대신 쓰지 않는다.
   ```
   먼저 본문을 소리 내어 3번 읽고 기도하신 뒤, 3줄을 적어 주세요.
   1. 마음에 걸린 단어/구절:
   2. 이 본문이 나에게 하는 말:
   3. 우리 성도에게 필요한 말:
   ```
   묵상요지가 있으면 설교자의 말 그대로 `01-묵상.md`에 저장한다.
5. 묵상이 있으면 `exegete` 에이전트로 E단계를 수행해 `02-주해.md`를 만든다.
6. 스킬의 보고 형식으로 마무리하고, 다음 명령으로 `/handoff gemini R`을 안내한다.
