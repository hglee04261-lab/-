대상: $ARGUMENTS (비어 있으면 가장 최근 설교 폴더)

1. `python3 .claude/hooks/check_sermon.py <폴더>/06-원고.md --report`를 실행해 자동 점검 결과를 얻는다.
2. `rubrics/최종점검-체크리스트.md`의 A~E 항목을 하나씩 판정한다.
   - 자동 판정 가능: `[검증필요]` 잔존, `[창작]` 표시 여부, 낭독 시간, AI 투 표현, 개인정보 패턴
   - 설교자 확인 필요: 직접 원문 확인 여부, 고백·교회 이야기 포함 여부 → 질문으로 남긴다
3. `07-검증.md`의 🔴 항목이 모두 처리되었는지 확인한다.
4. `AI-사용기록.md`의 빈 단계를 채우고, "돌아보기" 3칸은 설교자에게 묻는다.
5. 결과 보고:
   ```
   📋 최종 점검: 통과 n / 확인필요 n / 미통과 n
   ⏱ 낭독 예상: n분 (목표 n분)
   👤 설교자 확인 질문: ...
   🙏 마지막: 소리 내어 한 번 읽고, 기도로 마치세요.
   ```
6. 미통과가 0이면 `00-브리프.md`의 N단계 체크박스를 체크한다.
