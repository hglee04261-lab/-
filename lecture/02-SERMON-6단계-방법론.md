# Part 2. 최고의 설교를 위한 S.E.R.M.O.N. 6단계 (30분)

> **"설교 하나 써 줘"가 아니라, 6번 나눠서 묻는다.**
> 한 번에 다 맡기면 평균적인 설교가 나오고, 단계별로 맡기면 **나의 설교**가 나온다.

```
 S  Seek       기도·묵상          ← AI 끄기 (설교자만)
 E  Exegete    본문 주해          ← AI는 질문하는 조교
 R  Research   배경·자료 연구     ← AI는 출처 가져오는 사서
 M  Message    중심명제·목적      ← 결정은 설교자, AI는 스파링 상대
 O  Outline    개요·원고          ← AI는 초안 작가, 설교자는 편집장
 N  Nail-down  검증·완성          ← 다른 AI가 검증
              ─────────────────
              검증은 매 단계에서!
```

각 단계 = **목적 · 설교자의 일 · AI의 일 · 대표 프롬프트 · 함정**.
전체 프롬프트는 [prompts/](../prompts/) 폴더에 있습니다.

---

## S — Seek: 기도와 묵상 (AI 끄기)

- **목적**: 본문이 *나에게* 먼저 말씀하게 한다. 설교의 영적 진정성이 여기서 나온다.
- **설교자의 일**: 본문을 3번 소리 내어 읽고, 기도하며, 아래 3줄을 적는다.
- **AI의 일**: 없음. (원하면 번역본 대조표만 요청 가능)

```
묵상 메모 3줄
1. 마음에 걸린 단어/구절:
2. 이 본문이 나에게 하는 말:
3. 우리 성도에게 필요한 말:
```

> ⚠ 함정: AI부터 열면 AI의 해석이 내 묵상을 덮어 버린다. **최소 30분은 AI 없이.**

---

## E — Exegete: 본문 주해

- **목적**: 본문이 *원래* 무엇을 말했는지 정확히 본다.
- **설교자의 일**: 관찰 → 질문 → 답을 직접 확인(원어 성경, 주석).
- **AI의 일**: 답이 아니라 **좋은 질문**과 **구조 분석**을 내놓게 한다.

**대표 프롬프트 (Claude 추천):**
```
[본문] 누가복음 15:11-32
당신은 성경 주해 조교입니다. 아직 해석이나 적용은 하지 말고,
1) 문맥: 앞뒤 장(특히 15:1-2)과의 연결
2) 구조: 장면 단위로 나누고 반복·대조되는 표현
3) 관찰 질문 10개: 본문을 꼼꼼히 읽은 사람만 던질 수 있는 질문
4) 원어상 주목할 단어 3개: 원형(음역), 의미 범위, 과잉해석 주의점
을 표로 정리하세요. 확실하지 않은 내용은 [검증필요]로 표시하세요.
```

> ⚠ 함정: "어원 오류" — 단어 하나의 원어에 과도한 의미를 싣는 것. AI가 특히 좋아한다.

---

## R — Research: 배경·자료 연구

- **목적**: 역사·문화·지리 배경, 주석가들의 견해, 해석사를 확보한다.
- **설교자의 일**: 신뢰할 수 있는 자료를 고르고, 출처를 확인한다.
- **AI의 일**: **출처를 달아** 가져오게 한다. 내 서재 자료가 있다면 그 안에서만 찾게 한다.

**대표 프롬프트 (Gemini 추천):**
```
누가복음 15:11-32를 설교하려 합니다. 다음을 조사해 주세요.
1) 1세기 팔레스타인의 유산 분배 관습과 아버지가 달려가는 행동의 문화적 의미
2) 이 비유에 대한 주요 해석 3가지(학자명과 대표 저작 포함)
3) 각 항목마다 출처(저자, 제목, 연도, 가능하면 링크)
학술 자료와 일반 블로그를 구분해 표시하고, 출처를 찾지 못한 내용은 쓰지 마세요.
```

**내 서재 활용 (Gemini Notebook / Claude Projects):** 갖고 있는 주석 PDF, 신학 논문, 지난 설교를 올리고
`"올린 자료 안에서만 답하고, 근거가 된 자료와 위치를 표시하세요."`

> ⚠ 함정: AI가 준 출처를 **직접 확인하지 않고** 설교에서 인용하는 것.

---

## M — Message: 중심명제와 설교 목적

- **목적**: "이 설교는 한 문장으로 무엇인가?" + "청중이 무엇을 하기 원하는가?"
- **설교자의 일**: **결정.** 이것은 AI에게 넘길 수 없다.
- **AI의 일**: 후보를 내고, 내 후보를 비판한다(스파링).

**대표 프롬프트 (Claude 추천):**
```
지금까지의 주해(E)와 연구(R) 결과는 아래와 같습니다. [붙여넣기]
내 묵상 메모는 이렇습니다. [S단계 3줄]
1) 본문의 중심 사상(Exegetical Idea)을 한 문장으로
2) 설교의 중심명제(Homiletical Idea) 후보 3개 — 각각 장점과 위험
3) 설교 목적(청중이 알고/느끼고/행할 것) 후보 2개
내 묵상과 가장 잘 맞는 후보가 무엇인지 이유와 함께 말해 주세요.
```
그다음 → 설교자가 고르거나 직접 쓴다 → `"내가 정한 명제는 ○○입니다. 본문에 충실한지 비판해 주세요."`

> ⚠ 함정: AI가 낸 첫 번째 명제를 그대로 채택. 대개 무난하지만 평범하다.

---

## O — Outline & Write: 개요와 원고

- **목적**: 명제를 청중이 따라올 수 있는 흐름으로 만든다.
- **설교자의 일**: 구조 선택, 예화·적용 선별, 최종 문장 손질.
- **AI의 일**: 개요 여러 안, 예화·적용 후보 다수, 원고 초안, 문체 교정.

**순서:**
1. **개요 3안** (연역형 / 귀납형 / 내러티브형) → 하나 선택
2. **예화·적용 발상** (ChatGPT): 연령·상황별로 10개씩 → 3개 선택
3. **원고 초안** (Claude): 내 설교 2~3편을 샘플로 주고 "이 문체로"
4. **설교자 손질**: 내 고백, 우리 교회 이야기, 성령께서 주신 마음을 넣는다

**대표 프롬프트 (원고):**
```
아래는 제 지난 설교 원고 2편입니다. [붙여넣기]
문장 길이, 호흡, 청중을 부르는 말, 자주 쓰는 표현을 분석하고
이 문체로 다음 개요의 원고 초안을 써 주세요. [개요]
분량: 25분(약 7,500자). 예화는 [예화 후보]만 사용하고 새로 지어내지 마세요.
```

> ⚠ 함정: AI 원고를 거의 그대로 읽는 것. 청중은 "설교자의 고백"이 빠진 것을 금방 안다.

---

## N — Nail-down: 검증과 완성

- **목적**: 틀린 것, 위험한 것, 안 들리는 것을 걸러낸다.
- **설교자의 일**: 최종 판단, 소리 내어 읽기, 기도.
- **AI의 일**: **작성한 AI가 아닌 다른 AI**가 검증한다.

**4중 검증 (프롬프트 하나씩, [prompts/04-교차검증.md](../prompts/04-교차검증.md)):**
| 검증 | 추천 AI | 질문 |
|---|---|---|
| 사실 | Gemini | 인용·통계·역사·인물 일화가 사실인가? 출처는? |
| 신학 | Claude | 본문을 벗어난 주장, 율법주의·번영신학·도덕주의는 없는가? |
| 설교학 | Claude | 명제가 일관되게 흐르는가? 서론·결론·전환이 자연스러운가? |
| 청중 | ChatGPT (음성) | 우리 교회 ○○세대 성도가 듣는다면 어디서 지루하거나 상처받을까? |

**마지막**: 설교자가 원고를 소리 내어 읽고(시간 측정), 기도로 마친다.

> ⚠ 함정: 원고를 쓴 AI에게 "검토해 줘" → 대개 "훌륭합니다"라고 한다.
