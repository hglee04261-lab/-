## 2. 릴레이 시연 스크립트 (17분)

본문: 누가복음 15:11–32 / 청중: 장년 주일예배 / 묵상 메모(미리 준비):
```
1. 마음에 걸린 구절: "아직도 거리가 먼데 아버지가 그를 보고 측은히 여겨 달려가"(20절)
2. 나에게: 나는 돌아온 동생인가, 문 밖의 형인가
3. 성도에게: 교회 안에 있지만 아버지 마음을 모르는 '형' 같은 신앙
```

### ① Claude — E단계 (3분)
[prompts/03-claude.md](../prompts/03-claude.md) **C-1 주해 조교** 붙여넣기 → 구조·관찰 질문 확인.
👉 청중에게 보여 줄 것: AI가 15:1–2(바리새인의 수군거림)와 연결하는지, 형의 이야기가 결말이 열려 있다는 것을 짚는지.

### ② Gemini — R단계 (4분)
[prompts/01-gemini.md](../prompts/01-gemini.md) **G-1 배경 리서치** 붙여넣기.
👉 보여 줄 것: 출처 링크를 **하나 클릭해서 실제로 열어 보기**. "이게 검증입니다."
(시간이 있으면 Gemini Notebook에 주석 PDF를 올려 둔 화면을 보여 줌)

### ③ 핸드오프 → Claude — M단계 (3분)
Gemini 결과를 [templates/핸드오프-패킷.md](../templates/핸드오프-패킷.md) 양식에 붙여 Claude로 넘김 → **C-3 명제 스파링**.
👉 보여 줄 것: 명제 후보 3개 중 **강사가 직접 고르고 이유 말하기**. 예:
> "아버지는 집 나간 아들뿐 아니라 집 안의 아들에게도 달려 나가신다."

### ④ ChatGPT — O단계 발상 (3분)
**P-2 예화·적용 발상**: "40~60대 장년 직장인에게 와닿는 '집 안의 형' 같은 신앙 예화 10개"
👉 보여 줄 것: 아이디어의 양. 그리고 **"이 중 실제 있었던 일은 몇 개죠?"** 라고 다시 물어보기 → 지어낸 이야기를 실화처럼 말하는 위험을 직접 보여 줌.

### ⑤ Claude — O단계 원고 (2분)
**C-5 내 문체로 원고**: 미리 준비한 강사 설교 샘플 2편 + 개요 → 서론 부분만 생성.

### ⑥ 교차검증 — N단계 (2분)
- Claude가 쓴 서론을 **Gemini에** → "사실 검증" 프롬프트
- **ChatGPT 음성 모드**로 서론을 읽어 주고 "60대 권사님 입장에서 반응해 주세요"

## 4. 자주 묻는 질문

**Q. 셋 다 유료로 써야 하나요?**
A. 아닙니다. 무료로 시작하고, **가장 자주 쓰는 하나만 유료**로 하세요. 원고 작업이 많다면 Claude, 자료조사가 많다면 Gemini, 다용도라면 ChatGPT.

**Q. 하나만 쓴다면?**
A. 그래도 6단계를 지키고, N단계 검증만큼은 **다른 AI의 무료 버전**으로 하세요.

**Q. 시간이 더 들지 않나요?**
A. 처음 2~3주는 더 듭니다. 익숙해지면 자료조사 시간이 크게 줄고, 그만큼 **묵상과 기도에 시간을 돌려주는 것**이 목표입니다.
