# N단계 최종 점검 체크리스트

설교 전날, 원고를 이 목록으로 확인합니다. (Level 3에서는 `/finalize`가 자동 점검)

## A. 사실·인용 (환각 점검) — 하나라도 ✕면 수정
- [ ] 원고에 `[검증필요]`가 하나도 남아 있지 않다
- [ ] 모든 인용문의 저자·출처를 **직접** 확인했다 (AI 답변만으로 확인한 것은 확인이 아님)
- [ ] 통계·숫자의 출처와 연도가 있다
- [ ] 성경 장절과 인용 본문이 정확하다 (개역개정 대조)
- [ ] 원어 설명이 사전/주석으로 확인되었고 어원 오류가 없다
- [ ] 창작 예화를 실화처럼 말하지 않는다
- [ ] 유명인의 일화·명언이 실제로 확인된 것이다

## B. 신학
- [ ] 본문이 말하는 것을 말하고, 말하지 않는 것을 말하지 않는다
- [ ] 은혜가 먼저이고, 응답(순종·성결)이 그 열매로 제시된다
- [ ] 율법주의·도덕주의("~해야 합니다"의 나열) 경향이 없다
- [ ] 번영신학·값싼 은혜 경향이 없다
- [ ] 그리스도와 복음이 분명히 드러난다
- [ ] 소속 교단(성결 전통)의 신앙고백과 충돌하지 않는다

## C. 설교학
- [ ] 중심명제를 한 문장으로 말할 수 있고, 원고 전체가 그 명제를 섬긴다
- [ ] 서론 30초 안에 청중의 관심을 붙잡는다
- [ ] 대지 간 전환 문장이 있다
- [ ] 적용이 구체적이다 (누가, 언제, 무엇을)
- [ ] 결론에 새 내용이 없다
- [ ] 구어체로 소리 내어 읽었을 때 자연스럽다
- [ ] 낭독 시간이 배정 시간 안이다 (한국어 약 300자/분 기준)

## D. 설교자의 목소리
- [ ] 묵상(S)에서 받은 것이 원고에 살아 있다
- [ ] 나의 고백 또는 우리 교회 이야기가 최소 한 곳 있다
- [ ] AI 특유의 표현("~할 수 있습니다", "결론적으로", "여정", "깊이 있게")을 걸러냈다

## E. 윤리
- [ ] 성도 개인정보가 원고·AI 대화 어디에도 없다
- [ ] 다른 설교자의 원고를 재구성한 부분이 없다
- [ ] AI 사용기록을 작성했다
