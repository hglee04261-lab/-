# 🟦 Gemini 프롬프트 카드 — 자료 담당

`[ ]` 안만 바꿔서 쓰세요. 모든 카드는 **출처 없는 내용은 쓰지 않게** 설계되어 있습니다.

---

## G-1 배경 리서치 (R단계) ★
```
[본문]을 설교하려 합니다. 다음을 조사해 주세요.
1) 본문의 역사적·문화적·지리적 배경 중 설교에 중요한 것 3~5가지
2) 본문에 대한 주요 해석 입장 3가지와 대표 학자·저작
3) 한국어로 읽을 수 있는 신뢰할 만한 주석·논문 (있다면)
각 항목마다 출처(저자, 제목, 연도, 링크)를 달고,
출처 등급을 [학술] [교계 자료] [일반 웹]으로 표시하세요.
출처를 찾지 못한 내용은 쓰지 말고 "출처 미확인"이라고만 적으세요.
```

## G-2 Deep Research — 한 주제 깊게 (R단계)
```
주제: [예: 1세기 유대 사회의 유산 분배와 장자권]
설교 준비를 위한 배경 보고서를 작성해 주세요.
- 분량: A4 2쪽 이내
- 구성: 핵심 요약 5줄 → 상세 → 설교에 쓸 수 있는 포인트 3개 → 참고문헌
- 1차 자료(고대 문헌)와 2차 자료(현대 연구)를 구분하세요.
```

## G-3 내 서재에 묻기 (Gemini Notebook) (R단계)
노트북에 주석 PDF·논문·지난 설교를 올린 뒤:
```
올린 자료 안에서만 답하세요. 자료에 없으면 "자료에 없음"이라고 하세요.
[본문]의 [구절/주제]에 대해 각 자료가 무엇을 말하는지
자료별로 정리하고, 근거 위치를 표시해 주세요.
견해가 서로 다른 지점이 있다면 따로 정리해 주세요.
```

## G-4 번역본 대조 (E단계 보조)
```
[본문]을 개역개정, 새번역, 공동번역, 그리고 영어 ESV, NIV로 나란히 표로 보여 주고,
번역이 크게 다른 구절에 표시한 뒤 그 차이가 왜 생겼는지 짧게 설명해 주세요.
본문 인용은 반드시 정확해야 하며, 확실하지 않으면 [검증필요]로 표시하세요.
```

## G-5 사실 검증 (N단계) ★
```
아래는 설교 원고입니다. 사실 검증만 해 주세요(신학·문체는 평가하지 마세요).
원고에 나오는 모든 ① 인용문 ② 통계·숫자 ③ 역사적 사건 ④ 인물 일화 ⑤ 성경 장절을 찾아
표로 만들고, 각각 [사실 확인됨 + 출처] / [다르게 알려짐 + 정정] / [확인 불가]로 판정하세요.
---
[원고 붙여넣기]
```

## G-6 시각 자료 (확장)
```

16:9, 글자 없이, 차분하고 따뜻한 색감, [이미지 요소 예: 멀리서 달려오는 아버지의 실루엣, 저녁 노을].
특정 인물의 얼굴이 사실적으로 드러나지 않게 해 주세요.
```
