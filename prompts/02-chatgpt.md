# 🟩 ChatGPT 프롬프트 카드 — 발상 담당

ChatGPT는 **양**이 강점이고 **그럴듯한 지어내기**가 약점입니다.
그래서 모든 카드에 "실화/창작 구분" 규칙을 넣었습니다.

---

## P-1 설교 제목·도입 질문 발상 (O단계)
```
본문: [본문]
중심명제(확정, 바꾸지 마세요): [명제]
청중: [예: 40~60대 중심 장년, 수도권 중형교회]
1) 설교 제목 후보 10개 (짧고 기억에 남게, 진부한 표현 금지)
2) 서론을 여는 질문 5개 (청중이 속으로 "맞아" 할 만한 일상 질문)
```

## P-2 예화·적용 발상 (O단계) ★
```
중심명제: [명제]
청중: [청중 정보]
이 명제를 살릴 예화 후보 10개를 주세요. 각각:
- 한 줄 요약
- 유형: [실화-출처 있음] / [일반적 상황-창작] / [문학·영화] 중 하나
- 실화라면 출처, 확실하지 않으면 [검증필요]
주의: 창작 예화를 실화처럼 쓰지 마세요. 유명인의 일화나 명언을 지어내지 마세요.
그리고 청중이 이번 주에 실천할 수 있는 구체적 적용 5개(연령·상황별)를 주세요.
```

## P-3 설교 리허설 — 음성 모드 (N단계) ★
음성 모드를 켜고:
```
지금부터 제가 설교의 [서론/1대지/결론]을 읽겠습니다.
당신은 [예: 교회 다닌 지 30년 된 60대 권사님]입니다.
다 들은 뒤 1) 마음에 남은 한 문장 2) 지루하거나 이해가 안 된 부분
3) 혹시 상처가 될 수 있는 표현을 솔직하게 말해 주세요. 칭찬은 짧게.
```
→ 다른 청중으로 바꿔 반복: 20대 청년 / 처음 온 새가족 / 고난 중인 성도

## P-4 소그룹 나눔 교재 변환 (확장)
```
아래 설교 원고로 셀/구역 나눔지를 만들어 주세요.
- 마음 열기 질문 1, 본문 관찰 질문 2, 적용 질문 2, 기도제목 1
- A4 한 장, 인도자 팁 3줄 포함
---
[원고]
```

## P-5 반대편 목소리 (M·N단계)
```
제 설교 중심명제는 "[명제]"입니다.
이 명제에 대해 1) 회의적인 비신자 2) 신앙에 상처 입은 성도 3) 꼼꼼한 신학생
세 사람이 각각 던질 만한 반론이나 질문을 2개씩 주세요. 제 편을 들지 마세요.
```
