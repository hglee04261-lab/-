```
  01-묵상.md        ← 설교자만 작성
  02-주해.md
  03-연구.md
  04-명제.md
  05-개요.md
  06-원고.md        ← 저장할 때마다 자동 점검(훅)
  07-검증.md
  AI-사용기록.md
  handoff/
    to-gemini-R.md    from-gemini-R.md
    to-gpt-O.md       from-gpt-O.md
    to-gemini-N.md    from-gemini-N.md
```
